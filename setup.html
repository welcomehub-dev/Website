Setup Guide

Everything you need to get started, step by step.

02

Open the application

Once the download is complete, locate WelcomeHub.exe and open it to launch Welcome Hub.

  • Find the downloaded EXE file.
  • Double-click WelcomeHub.exe.
  • Wait for Welcome Hub to open.
Download the application only from the official Welcome Hub website.

Open App Library to discover applications available on your Windows computer.

05

Discover Explore

Use Explore to access convenient Windows tools and system locations from one place.

  • Open File Explorer.

06

Personalize your experience

Make Welcome Hub feel like yours with its personalization options.

  • Choose between light and dark themes.
  • Select an accent color.
  • Choose a background color.
  • Restore the default appearance whenever you want.
07

Start Welcome Hub with Windows

Want Welcome Hub to open automatically when you sign in? You can add a shortcut to the Windows Startup folder.

  • Find WelcomeHub.exe in its permanent location.
  • Right-click it and select Create shortcut.
  • Press Win + R on your keyboard.
  • Type shell:startup and press Enter.
  • Move the shortcut into the Startup folder.
This step is optional. Keep the original EXE in a permanent location so the shortcut continues to work.

You're ready to go!
