What is Welcome Hub?

Welcome Hub is a Windows desktop application that brings useful app shortcuts, Windows tools, and personalization settings together in one place.

How do I download Welcome Hub?

Visit the Download page and click the Download Welcome Hub button.

Once the executable finishes downloading, open the file to launch the application.

Go to Download →

How can I make Welcome Hub start automatically?

You can configure Windows to launch Welcome Hub automatically whenever you sign in.

  1. Locate your downloaded WelcomeHub.exe file.
  2. Right-click it and select Create shortcut.
  3. Press Win + R on your keyboard.
  4. Type shell:startup and press Enter.
  5. Copy the Welcome Hub shortcut into the Startup folder.
  6. Restart or sign out and sign back in to test it.
Tip: Put the shortcut in the Startup folder, not the original EXE itself. Keep the EXE in its permanent location so the shortcut continues working.
How do I change the appearance?

Open Welcome Hub and navigate to the Personalize section.

There you can choose a theme, change the accent color, adjust the background, or reset your settings.

How does the App Library work?

The App Library discovers applications available through your Windows Start Menu and displays them in a searchable library.

Select an application to launch it.

What can I find in Explore?

Explore provides shortcuts to useful Windows locations and tools, including:

  • File Explorer
  • Downloads
  • This PC
  • Windows Settings
  • Task Manager
  • Display and Sound settings
  • Storage and System Information
Where are my personalization settings saved?

Welcome Hub stores its settings in your Windows user profile, inside its application settings folder.

The settings are stored separately from the application executable.

How do I update Welcome Hub?

Visit the official Welcome Hub Download page and check for the latest published release.

Download the newest executable when an update becomes available.

What should I do if Welcome Hub does not open?

First, make sure the download completed successfully. Try opening the executable again.

If the problem continues, check whether Windows security software has blocked the application.

Which Windows versions are supported?

Welcome Hub is designed for Windows 10 and later.
